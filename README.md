# OmniManager Botillerías Standalone

Versión Windows standalone y offline de OmniManager para botillerías.

## Principios del proyecto

- Funcionamiento 100% local para la operación diaria.
- Sin landing page general ni selector de rubro.
- Inicio directo al sistema de licencia de OmniManager Botillerías.
- Demo local de 7 días.
- Licencias comerciales mensuales o anuales.
- Base de datos almacenada en el PC del cliente.
- Sin asistencia con IA.
- Sin dependencia de Firebase, Firestore, Cloud Run ni servicios externos para operar.
- Ejecutable/instalador de Windows; el cliente no debe ejecutar comandos manuales.
- La base de datos de cada cliente se prepara antes de entregar el instalador.

> Este repositorio es independiente de las instalaciones personalizadas existentes de OmniManager.
